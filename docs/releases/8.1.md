## Upgrade considerations - deprecation of old functionality

### Removed support for Python 3.10

Python 3.10 is no longer supported as of this release; please upgrade to Python 3.11 or above before upgrading Wagtail.

## Upgrade considerations - changes affecting Wagtail customizations

### `expand_db_html` accepts an optional `request`

`wagtail.rich_text.expand_db_html()` now accepts an optional `request` argument. Pass it so page links in rich text resolve against the current site in multi-site setups. The `{% richtext %}` template tag does this automatically from the template context; the `|richtext` filter accepts `{{ value|richtext:request }}`. `RichText.render(request=...)` and `RichTextBlock` (including StreamField / `{% include_block %}` rendering, and custom templates that output `{{ value }}`) use the same expansion when a request is in context. Custom rewrite handlers that implement `expand_db_attributes_many` may accept a `request` keyword argument; handlers that do not are unchanged.
